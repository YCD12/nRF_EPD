## 优化空间与剩余限制

1. **优先控制 Bootloader 体积。** 隔离试验添加 `-fno-inline-small-functions` 后占用 20,224 B，节省 172 B，静态 RAM 增加 4 B；布局、UICR、公钥及验签代码仍在。尚未采用：编译后的实际 DFU 行为和栈峰值需要硬件验证。当前生产镜像仍为 20,396 B。
2. **提高外置资源中断后的恢复能力。** 当前单份资源依赖网页内存旧包进行尽力恢复。掉电、断连、持续 Flash 故障或浏览器挂起超过 60 秒维护期限，仍可能需要重新保存/上传资源。可评估持久恢复记录或按实际包大小设计双槽；剩余 156 KiB 不能直接容纳第二份完整 256 KiB 字库分区。
3. **继续外移小常量要核算净收益。** 大块显示资源和用户数据已经外置。优先减少重复代码、读取和失败重绘，再考虑小表与文案，避免新增访问代码抵消节省。
4. **减少确定未写入时的恢复擦写。** 网页目前在上传调用前保守标记可能发生修改，部分 BEGIN 前失败也会恢复旧整包。未来可根据明确的上传阶段减少擦写，同时保留 BEGIN 确认丢失时的保守恢复。当前未扩大协议或缓存范围。
