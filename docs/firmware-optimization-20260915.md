# 固件优化与验证（2026-09-15）

本轮针对 nRF52811、800×480 黑白红屏、外置字体的当前配置，完成 RAM 优化、重复逻辑收敛及异步队列／存储可靠性修复。应用报告版本由 `0x2F` 升至 `0x30`。

## 构建结果

使用仓库 ARM GCC 9.3.1 工具链和发布链接脚本，未开启 RTT、BLE 日志或调试布局。以下为应用自身占用，不包含 SoftDevice 和 bootloader。

| 项目 | 优化前（字节） | 优化后（字节） | 变化 |
| --- | ---: | ---: | ---: |
| Flash：text + data | 52,572 | 53,136 | +564 |
| Flash 余量（应用区 57,344） | 4,772 | 4,208 | −564 |
| 静态 RAM：data + bss | 11,644 | 6,800 | −4,844（−41.6%） |
| 预留栈 | 2,048 | 2,048 | 不变 |
| 预留堆 | 0 | 0 | 不变 |
| RAM 余量（扣除静态区和预留栈） | 1,964 | 6,808 | +4,844 |

RAM 余量按应用 RAM 区 15,656 字节计算，不代表实测最大栈深度。优化前 `text/data/bss = 52280/292/11352`，优化后为 `52904/232/6568`。

Flash 没有净下降：图形分支裁剪等节省被新增的并发保护、异步存储重试和错误处理抵消。固定屏型裁剪相对本轮通用图形构建节省 448 字节 Flash。

## 实现变化

- 时钟局刷 OLD 缓冲从 4,352 字节缩为 512 字节。记录最后成功显示的时间，分条带重建 OLD 并生成 NEW；整个逻辑窗口提交完成后再触发物理刷新。任一阶段失败均使局刷状态失效，交由既有全刷路径恢复。
- GFX 分页缓冲从 2,560 字节缩为 1,536 字节；默认绘制复用静态缓冲。窗口分页数使用窗口实际高度。日历仅处理与当前页相交的日期区域，时钟页眉／页脚按页跳过，当天农历计算移出分页循环。
- 普通文本走直接输出接口，避免格式化缓冲；移除重复初始化。屏幕型号和驱动描述表改为只读，减少 RAM 搬运和常驻数据。
- 命令队列抽出共用操作，在临界区内复制及更新队列状态。保留两条待处理命令容量；区分已调度与正在执行，调度队列满时由主循环重试。
- 配置写入使用固定、对齐且尾部清零的快照，FDS 完成前不覆盖。初始化等待 FDS 就绪；清除配置等待未完成写入并确认删除结束后重启。
- 标注保存从接受请求起锁定数据，仅匹配本文件／记录的写入完成事件解除锁定；延后执行保存期间收到的清除请求。配置和标注共用存储重试与 GC 协调逻辑。
- 校时节流、字体刷新等待改用运行时秒计数，避免手动调整日期时间影响延迟判断。
- `Makefile.nRF52` 复用 `Makefile.nRF52_linux`，消除两份构建配置维护。固件默认启用 `GFX_FIXED_BWR_PANEL=1`，裁掉当前屏型不使用的旋转和四色分支；通用主机绘图默认保持这些能力。更换屏型／使用旋转时应设为 `0` 并重新验证。

## 验证

`tests/run_host_tests.sh` 全部通过：26 个 C 测试程序、13 个 Node 测试、3 个 Python 测试。ARM 发布构建和兼容 Makefile 入口构建通过，OTA 与完整 HEX 打包成功。

新增或扩展的重点覆盖：

- 命令入队中断交错、队列顺序／容量、避免重复调度、调度满后的恢复。
- FDS 异步初始化、写入快照、对齐填充、存储满／GC／提交队列满重试、保存中清除、无关事件隔离和删除完成判定。
- 通用与固定屏型两种绘图配置各 30 组完整画面，黑白／红色平面与优化前基准一致；包含月份边界、不同周起始日、密集标注、标注位置／字体／颜色和负温度。
- 时钟局刷每个 OLD／NEW 字节与完整重绘参考结果一致；覆盖分钟进位、分屏跨小时，以及条带写入失败、刷新失败和 BUSY 超时后的状态失效。

标准黑白红画面的外置字体读取回调计数如下。它衡量主机测试中的读取次数，不是实机刷新耗时；局刷重建 OLD 的成本也不能用这些完整画面数据推算。

| 画面 | 优化前 | 优化后 | 减少 |
| --- | ---: | ---: | ---: |
| 日历 | 26,240 | 20,658 | 21.3% |
| 分屏 | 29,040 | 14,387 | 50.5% |
| 时钟 | 8,720 | 2,297 | 73.7% |

## 产物与后续实机验证

产物位于 `output/optimization/release-build/`：

- `nrf52811_xxaa-ota.zip`：OTA 升级包。
- `nrf52811_xxaa-full.hex`：包含 SoftDevice、bootloader、应用及 settings 的完整镜像。
- `nrf52811_xxaa.hex`、`.bin`、`.out`、`.map`：应用镜像与链接结果。

应用 BIN 长度为 53,136 字节，打包报告 CRC 为 `E3D58B33`。DFU 包的 application version 沿用现有脚本值 `0x19`，与应用报告版本 `0x30` 是不同字段。测试日志保存在 `output/optimization/host-tests.log`；基线结果在 `output/current-review/`。这些 output 文件为本地构建产物，不纳入版本管理。

本轮未烧录硬件。合入或发布前仍需上板验证连续分钟／小时切换的局刷耗时与残影、BLE 密集命令下保存及清除配置、标注保存和掉电恢复，并确认实际最大栈用量。保留原有 2 KB 栈，未以缩栈方式换取表面 RAM 余量。
