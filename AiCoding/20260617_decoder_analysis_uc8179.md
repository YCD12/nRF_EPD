## Phase 1: 初始化与 LUT 加载 (336 bytes, 8ms)

### 寄存器配置序列 (寄存器命令+数据):

```
01 07 07 3F 3F   → PWR(0x01): VGH=20V VGL=-20V VDH=15V VDL=-15V
82 00             → VDCS(0x82): VCM_DC=0x00
06 27 27 2F 17    → BTST(0x06): Booster软启动参数
00 3F             → PSR(0x00): 面板设置 0x3F
                   bit[5:4]=11 → 使用寄存器LUT(非OTP)
                   bit[0]=1 → KW模式
61 03 20 01 E0    → TRES(0x61): 分辨率 0x0320×0x01E0 = 800×480
15 00             → 双SPI模式禁用
50 11 07          → CDI(0x50): VCOM和数据间隔
60 22             → TCON(0x60): 时序控制 0x22
65 00 00 00 00    → GSST(0x65): Gate/Source位置偏移 = 0
```

### LUT (查找表) 数据

**格式**: 60字节/表, 前6字节 = [波形类型, T1, T2, T3, T4, 重复次数], 后54字节 = 0填充

| 寄存器 | 命令 | 波形 | T1 | T2 | T3 | T4 | 重复 | 说明 |
|--------|------|------|----|----|----|----|------|------|
| LUTC | 0x20 | `00` | 15 | 15 | 0 | 0 | 1 | VCOM通用LUT(不刷新) |
| LUTWW | 0x21 | `10` | 15 | 15 | 0 | 0 | 1 | 白→白 |
| LUTBW | 0x22 | `10` | 15 | 15 | 0 | 0 | 1 | 黑→白 |
| LUTWB | 0x23 | `80` | 15 | 15 | 0 | 0 | **2** | 白→黑 |
| LUTBB | 0x24 | `80` | 15 | 15 | 0 | 0 | 1 | 黑→黑 |

**波形代码解析**:
- `0x00`: 保持/不刷新
- `0x10`: 固定电压驱动 (白保持或黑变白)
- `0x80`: 极性翻转驱动 (白变黑时用)

**注意**: T1=T2=15 (0x0F) 对应具体时钟周期数, 不是毫秒。LUTWB的repeat=2表示白→黑转换执行两轮驱动,其他为1轮。

## Phase 2: 局刷RAM1 (黑层) 写入 (40681 bytes)

### 命令序列:

```
82 22           → VDCS(0x82): VCM_DC = 0x22
50 A9 07        → CDI(0x50): VCOM和数据间隔 = 0xA9, 0x07
91              → PTIN(0x91): 进入局部模式
90 01 B8 03 1E  → PTL(0x90): 局部窗口设置
   00 00 01 25  →   x=440(0x01B8) xe=798(0x031E) y=0 ye=293(0x0125)
   00           →   扫描模式=正常
10              → DTM1(0x10): 开始传输黑层数据
FF...           → 图像数据 (40664字节,含黑底图像+中途FLG轮询)
```

### 局部窗口坐标

| 参数 | 原始值 | 实际值 |
|------|--------|-------|
| x_start | 0x01B8 | 440 |
| xe_end | 0x031E | 798 |
| y_start | 0x0000 | 0 |
| ye_end | 0x0125 | 293 |
| 宽度 | 798-440+1 | 359px → 字节对齐45B=360px |
| 高度 | 293-0+1 | 294px |
| RAM字节 | 45×294 | **13230B**/层 |

### 图像数据分析

非0xFF数据集中在时间/数字区域(偏移322字节后,每45字节模式重复)。
SPI数据在传输过程中间插FLG(0x71)状态轮询。

## Phase 3: 局刷RAM2 (红层) 写入 (40988 bytes)

命令序列与Phase 2完全相同, 差异:

```
82 22           → VDCS(0x82): VCM_DC = 0x22
50 A9 07        → CDI(0x50): VCOM = 0xA9
91              → PTIN
90 01 B8 03 1E  → PTL: 同一窗口 (440,0)-(798,293)
   00 00 01 25
   00
13              → DTM2(0x13): 开始传输红层数据 (非DTM1!)
FF...           → 0xFF为主(保持无红),含零星非FF数据
```

**关键**: DTM2(0x13)代替DTM1(0x10), 写入颜色层RAM。数据大部分为0xFF表示无红色。

---

## Phase 4~19: 繁忙轮询 (1.6s)

```
71  (17次, 每次间隔~100ms)  → FLG(0x71): 读取状态寄存器(BUSY脚)
12                     → DRF(0x12): 显示刷新命令(仅在第1次FLG前发出)
```

**时序**: 
1. DRF(0x12)命令第一个发出 → 启动显示刷新
2. 连续17次FLG(0x71)轮询 @100ms间隔 → 检查刷新是否完成
3. ~1.6s后刷新完成

---

## Phase 20~21: 退出局部模式 + 深度睡眠 (2.9s)

```
92 02    → PTOUT(0x92): 退出局部模式, 数据0x02
07 A5    → DSLP(0x07): 深度睡眠, 确认码0xA5
```

## 总结

该trace完整记录了一次 **UC8179局部刷新(Partial Refresh)** 操作:

1. **寄存器初始化**: PWR+VDCS+BTST+PSR+TRES+CDI+TCON+GSST (不含PON)
2. **加载局刷LUT**: 5×60字节局刷波形表(T1=T2=15, T3=T4=0)
3. **写黑层RAM(DTM1)**: 局部窗口x=[440,798] y=[0,293], 写数字时钟图像数据
4. **写红层RAM(DTM2)**: 同一局部窗口, 0xFF为主(无红色)
5. **DRF+FLG轮询**: 显示刷新+1.6s等待刷新完成
6. **PTOUT退出局刷 → DSLP深度睡眠**

整个流程从第一个有效字节到深度睡眠约 **2.9秒**。
未观察到全刷序列, 可能全刷在捕获开始前已完成。
